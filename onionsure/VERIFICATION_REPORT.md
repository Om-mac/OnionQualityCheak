## 4. Central Lot ID Integrity (spec §: "One physical lot = one Central Lot ID")

Verified by the cross-center test:
- A second `POST /inspection/start` on the **same lot** creates a **new inspection session** but **zero new lots** (`lots` count before == after).
- The `POST /lots` route deduplicates on `lotNumber`/`centralLotId` — re-submitting an existing Central Lot ID returns the existing lot instead of creating a duplicate.
- `GET /lots/lookup/:lotNumber` aggregates **all** inspections for that Central Lot ID across centers and flags `resultVariationDetected` when grades differ by center.

## 5. Code Completed (the app was *incomplete*; these gaps were closed)

| File | Change | Why |
|---|---|---|
| `server/api.js` | New public `POST /auth/farmer-signup` route (previously only admin-gated `/auth/register` existed) | New farmers could not self-register; spec requires farmer self-signup → real DB user |
| `server/api.js` | `farmer-signup` resolves FPO by free-text `fpoName` → real `fpoId`; `bcrypt` required; `const d = db.get()` hoisted to fix TDZ bug | Wire signup form to real FPO + secure password hashing |
| `web/src/lib/api.ts` | `register` now calls `/auth/farmer-signup` and returns `{ token, user }` | Frontend must use the new public signup endpoint |
| `web/src/lib/auth.tsx` | `register` callback stores the returned JWT (auto-login) | After signup the farmer lands logged-in on their dashboard |
| `web/src/pages/Login.tsx` | Added full signup form (Full Name, Mobile, Village, FPO, Username, Password) + mode toggle | Spec login page had no farmer self-registration UI |
| `web/src/pages/farmer/Dashboard.tsx` | Added lot-creation flow, "NO ACTIVE LOT" empty state, success banner showing the **Central Lot ID**, and "AWAITING INSPECTION" state | Farmer dashboard had no lot-submission path; spec requires it |
| `web/index.html` | Added an inline SVG favicon (onionsure leaf) so the browser doesn't 404 on `/favicon.ico` | Eliminate spurious browser-side 404 surfaced by the headless audit |
| `server/seed.js` | Aligned seed to spec (3 farmers, 3 officers, 10 lots) | Spec explicitly lists required seed counts |

**Bug fixed during verification:** a stray `]` (`gradeCounts.REJECTED]`) in `Dashboard.tsx` that broke compilation, and a temporal-dead-zone error (`d` used before declaration) in `farmer-signup` — both caught and fixed.
